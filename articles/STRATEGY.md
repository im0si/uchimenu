# うちめにゅー SEO戦略書

すべての記事はこの設計に従う。この設計にないKWの記事は作らない。

## 1. 前提: 何のためのSEOか

- CV定義: **記事 → /app/ 訪問 → ガチャ実行**（将来はプレミアム転換の母数）
- したがって狙うのは「読んで満足する記事」ではなく、**検索者の悩みがうちのツールで数十秒で解決するKW**のみ
- レシピ単体KW（例:「肉じゃが レシピ」）は大手（クラシル・DELISH・クックパッド）の牙城かつツール誘導が弱いため**全面的に狙わない**

## 2. ターゲットユーザー（2ペルソナ）

| | P1: 献立疲れの家庭料理人 | P2: 外食ランチの痩せたい社会人 |
|---|---|---|
| 悩み | 毎日「夕飯なに作ろう」で消耗 | 外食続きで太る。でも自炊は夜だけ |
| 刺さる機能 | ガチャ・週間ガチャ・買い物リスト | ランチ記録・夕食予算・カスタマイズガチャ |
| 検索の型 | 「決まらない」「決め方」「自動」 | 「◯kcal」「食べすぎた」「リカバリー」 |

## 3. KWティア設計（優先度順）

### Tier S: ツール探索KW（CVR最高・最優先で1位を取る）
検索者が「決めてくれる何か」を探している。うちが答えそのもの。競合は弱小ツール・アプリ紹介記事のみで勝てる。
- 献立 ルーレット／夕飯 ルーレット
- 献立 ガチャ
- 献立 決めてくれる（アプリ・サイト）
- 献立 自動／献立 自動作成 無料
- 今日の夕飯 おまかせ／診断

### Tier A: 悩み直撃KW（ボリューム大・準指名）
- 夕飯 決まらない／晩ごはん 思いつかない
- 献立 考えるのがストレス／めんどくさい
- 献立 決め方
→ pillar記事1本＋派生。解決策の1つとしてツールへ自然接続。

### Tier B: カロリー×夕食KW（カスタマイズ機能に直結）
- 夕食 500kcal 献立／夕食 600kcal 献立（数字別にシリーズ化）
- ダイエット 夕食 何kcal
- 誤差50kcal保証・品数指定という**機能そのものが差別化コンテンツ**になる

### Tier C: 食べすぎリカバリーKW（ランチ記録に直結・競合が弱い穴場）
- 昼 食べ過ぎた 夜ごはん
- 食べ過ぎた 次の日 リセット
- 飲み会 翌日 食事
→ 「残りkcal自動計算」はこのKW群への唯一無二の回答。

### Tier D: 週間献立KW（週間ガチャ・買い物リストに直結）
- 献立 1週間 立て方（※「1週間 献立 レシピ」は大手強で狙わない。「立て方」「自動」「買い物リスト」複合で取る）
- 献立 買い物リスト 作り方

## 4. カテゴリ設計（サイト構造）

WPカテゴリは以下5つに固定。1記事1カテゴリ。テーマの色マップもこの名称に一致させる。

| カテゴリ名 | スラッグ | 対応Tier | 色 |
|---|---|---|---|
| 献立の決め方 | kimekata | S・A | 朱 |
| カロリー別 夕食献立 | kcal | B | 抹茶 |
| 食べすぎリカバリー | recovery | C | 藍 |
| 1週間の献立と買い物 | week | D | 山吹 |
| うちめにゅーの使い方 | guide | 指名・機能解説 | 桜 |

構造: 各カテゴリに pillar（総合解説）1本 ＋ cluster（個別KW）N本。cluster→pillar、pillar→clusterを必ず内部リンク。

## 5. 記事品質基準（全記事共通の型）

1. タイトル: 対策KWを前方に・32字前後・数字か具体性を入れる
2. meta description（excerpt）: 100〜120字でKWを含み、記事の答えを予告
3. 導入: 3行以内に検索意図への「答え」を先出し
4. 見出し: サジェスト・関連検索・PAAを網羅するH2を6〜10本。H2にも共起語
5. 独自性（必須・最低2つ）: 186品DBからの実数kcal表／機能スクショ的説明／計算根拠（Mifflin-St Jeor・脂肪1kg=7200kcal）／オリジナルの図解
6. CTA: 記事中盤に1回（文脈に沿ったdeep link付き `[gacha_cta]`）＋末尾自動CTA。中盤CTAは「その段落の悩み」に対応するパラメータを付ける
7. FAQ: H2「よくある質問」に3問以上（PAA対策）
8. 文字数目安: Tier S=3,000〜4,000字／Tier A pillar=5,000〜7,000字／その他=3,500〜5,000字
9. 表記: だ・である調は使わない。です・ます。煽らない。医療・健康断定をしない（「目安」「といわれます」）

## 8. 計測

- Search Console: カテゴリ別・記事別の表示/CTR/掲載順位を月次確認
- 60日で掲載順位が付かない記事はタイトル・見出しをリライト
- CVはWP側でCTAクリック（GA4イベント）を計測。アプリ側には計測を入れない
